Gamemodes:
Classic:
Navigate with the navigation buttons and toggle lights with A, but be careful,
each light also toggles the adjacent lights. Turn them all off (i.e. make them
a black square) to win.

Alternative
Like Classic mode, only the light you click doesn't toggle (it's adjacent
lights still do)

Threeway
Like Classic mode, only the light have a 3rd (dimmed) state which is now
included in their cycle.

Super Position
Like Classic mode, only a new superposition state is added. A light in super
position counts as off, valid solutions might require lights in superpositions
and off states.
